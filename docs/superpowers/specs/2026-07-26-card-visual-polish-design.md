# 卡牌视觉细节修正设计

## 1. 目标

本轮只修正当前卡牌模板的四个可见问题：

1. 费用数字在费用球内视觉居中，并加粗、增强轮廓。
2. 卡牌名称在标题栏内水平与垂直居中，并加粗。
3. 卡图透明区域使用随卡牌颜色变化的柔和浅色渐变填充。
4. 类型铭牌叠加在参考资源原有横梁上，消除横梁被截断和拼接不连续的问题。

卡牌尺寸、战斗逻辑、数据格式、交互行为和角色立绘资源均不在本轮范围内。

## 2. 当前问题与根因

### 2.1 费用

`EnergyCost` 虽然设置了水平和垂直居中，但当前字体字重较轻，数字轮廓和圆形费用球的装饰重心不一致，视觉上表现为偏移和不够醒目。不同长度的费用文本也共用同一字号，无法稳定控制占位。

### 2.2 卡名

`CardName` 只通过 BBCode 做了水平居中，`RichTextLabel` 仍按顶部排版；基础字体没有粗体变化，因此文字贴近标题栏上沿且识别度不足。

### 2.3 卡图背景

角色立绘 PNG 带透明通道，当前卡图区域没有独立底色层，透明部分直接显示战斗场景，导致卡面缺少完整背景。

### 2.4 类型横梁

资源生成器目前会把母版中间类型铭牌区域整体清空，再用包含大量透明边缘的宽裁片进行九宫格缩放。结果是原横梁被挖空，覆盖资源又不能严密补回，呈现为卡牌中段被截断。

## 3. 图层结构

卡牌运行时从下到上的绘制顺序调整为：

1. `CardArtBackground`：卡图渐变底色。
2. `CardTexture`：透明角色立绘。
3. `CardChrome`：由参考图生成的完整卡框母版，保留中间横梁。
4. `CardTypeBackground`：从参考图精确裁切的中央类型铭牌。
5. `CardType`、`CardName`、`EnergyCost`、描述和星级文字。

渐变层和立绘层必须使用相同显示区域。完整母版负责卡框与横梁连续性，类型资源只负责覆盖横梁中央铭牌，不参与补齐两侧结构。

## 4. 版式规格

### 4.1 卡牌名称

- 节点区域：`Rect2(34, 6, 90, 24)`。
- 水平对齐：居中。
- 垂直对齐：居中。
- 最大字号：12。
- 自动缩小下限：8。
- 使用 `FontVariation` 增加字重，目标 `variation_embolden = 0.65`。
- 白色文字，深色 2 像素描边。
- 长名称允许缩小字号，不允许越出标题栏或遮挡右侧徽记。

### 4.2 费用

- 节点区域：`Rect2(2, 3, 38, 38)`。
- 水平与垂直对齐：居中。
- 使用 `FontVariation` 增加字重，目标 `variation_embolden = 0.8`。
- 1 至 2 个字符使用 19 像素字号；3 个及以上字符使用 14 像素字号。
- 白色文字，深色 3 像素描边。
- 数字对齐以费用球有效圆形区域为准，不以左上装饰尖角为准。

### 4.3 卡图区域

- 完整母版模式：`Rect2(17, 34, 114, 94)`。
- 旧资源回退模式：`Rect2(15, 34, 116, 76)`。
- `CardArtBackground` 与 `CardTexture` 始终同步使用同一矩形。
- 卡图保持当前缩放与裁切方式，不修改角色立绘文件。

### 4.4 类型铭牌

- 运行时区域：`Rect2(49, 119, 48, 14)`。
- 采用 `TextureRect` 等比缩放，不再使用会拉伸透明边缘的九宫格面板。
- 类型文字保持居中，字号 9，白色文字配深色描边。
- 类型铭牌只覆盖横梁中央，不能遮挡横梁两侧连接结构。

## 5. 渐变规则

采用用户确认的方案 1：柔和浅色渐变。

- 方向：左上至右下。
- 起点：卡牌主色与近白色混合，保持高明度。
- 中段：主色的浅色版本。
- 终点：饱和度受控的主色，仍需保证角色轮廓可读。
- 推荐采样：
  - `0.00`：主色 `lightened(0.88)`。
  - `0.55`：主色 `lightened(0.68)`。
  - `1.00`：主色 `lightened(0.38)`。
- 渐变全程不透明，只填补立绘透明区域。
- 当卡牌颜色数据缺失时，使用中性银灰渐变，不显示透明战斗背景。

渐变由运行时根据现有卡牌颜色生成，不新增逐卡背景图片，不增加后续美术出图量。

## 6. 参考资源处理

### 6.1 完整母版

- 继续使用 `designer/art_source/card_styles/full_master_v1/card_master_chroma.png` 作为唯一母版来源。
- 移除绿色背景时，保留参考图原有的类型横梁和两侧连接装饰。
- 不再清空 `_is_master_ribbon_body` 判定区域。
- 红、蓝、绿、金、银卡框仍由母版颜色映射生成，不绘制新的结构色块。

### 6.2 类型铭牌

- 从参考图中按 `Rect2i(358, 874, 358, 94)` 精确裁取中央铭牌。
- 输出参考尺寸为 `192 x 56`，保持约 `3.43:1` 的原始比例。
- 只移除裁片中属于横梁连接段的紫色像素，保留铭牌本体、暗边和高光。
- 基于参考铭牌的明暗关系映射攻击、技能、能力、状态和诅咒五种颜色。
- 禁止使用纯色矩形、程序绘制边框或额外色块拼接类型区域。

## 7. 异常与回退

- 完整母版或类型铭牌任一资源缺失时，沿用现有原子回退逻辑，避免半套新模板与旧模板混用。
- 卡牌颜色缺失时使用银灰卡框与中性渐变。
- 类型值无法识别时使用状态类型铭牌作为视觉回退，不改变卡牌逻辑。
- 费用文本为空时不显示数字，但费用球结构保持不变。

## 8. 验收标准

### 8.1 自动检查

- 卡名节点水平、垂直居中，使用加粗字体变化，字号范围为 8 至 12。
- 费用节点水平、垂直居中，使用加粗字体变化，并按字符长度切换字号。
- `CardArtBackground` 位于立绘下方，且与立绘矩形完全一致。
- 不同卡牌颜色生成不同的浅色渐变。
- `CardTypeBackground` 使用等比纹理节点，尺寸和位置符合规格。
- 完整母版在类型横梁中心保持非透明，类型铭牌纹理具有有效透明边界且比例正确。
- 生成资源不存在绿色抠图残边。

### 8.2 视觉检查

- 在卡牌预览页同时检查红、蓝、绿三种常用卡色。
- 检查 0、1、2 和多字符费用的视觉重心。
- 检查短名称和最长名称，文字不能贴边、溢出或遮挡徽记。
- 检查攻击、技能、能力三类铭牌，横梁两侧必须连续，铭牌不得表现为挖空或补丁。
- 检查透明面积较大的角色立绘，战斗背景不能透过卡图区域。
