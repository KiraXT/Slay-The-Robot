# Red Character Art Unification Design

**Goal:** 以当前已替换的 Tifa 风格红色角色立绘为基准，统一红色角色的直接关联美术资源，优先消除战斗、卡牌和 UI 中的风格割裂感。

**Scope:** 本轮只处理红色角色链路，不扩展到蓝/绿/橙角色，也不处理整套遗物、敌人或 UI 重构。

## 目标范围

本轮执行方案 B，替换以下 4 组资源：

1. `character_red_icon.png`
2. `character_red_text_energy.png`
3. 红色卡组共用卡图 `external/sprites/cards/red/card_red.png`
4. 红色角色高频单卡插图：
   - `card_attack_basic.png`
   - `card_attack_big.png`
   - `card_grant_energy.png`
   - `card_weaken_enemies.png`
   - `card_block_basic.png`
   - `card_draft_random_attack.png`

## 不在本轮范围内

- 蓝/绿/橙角色的立绘、头像、能量图标
- 非红色卡组共用卡图
- 红色角色起始遗物、消耗品、敌人立绘
- UI 结构调整
- 卡牌数据字段、资源加载逻辑重构

## 设计原则

### 1. 人设统一

所有新资源以当前红色角色战斗立绘为唯一视觉锚点：

- 黑长发
- 红黑白主色
- 近战、拳击、格斗型气质
- 带轻机械战斗配件
- 动作姿态偏主动、偏近战

### 2. 风格统一

统一采用以下视觉方向：

- 手绘卡通插画风
- 非纯写实
- 保持较清晰轮廓
- 缩小后仍能辨认主体和动作
- 卡图不使用复杂背景
- icon 不使用完整全身人物缩略

### 3. 资源用途导向

不同资源按显示场景分别设计：

- 头像：优先脸部识别度
- 能量图标：优先符号化表达
- 共用红卡图：优先体现红色角色职业感
- 高频单卡：优先体现具体动作语义

## 各资源设计说明

### A. 角色头像 `character_red_icon.png`

**用途：** 新开局角色选择按钮、角色识别入口。

**规格：**

- 256x256
- 透明底 PNG

**设计要求：**

- 使用半身或近景头像
- 脸部与红色拳套需要同时可辨认
- 不要缩小整张立绘硬塞进头像框
- 表情应保留自信、战斗准备感

### B. 角色能量图标 `character_red_text_energy.png`

**用途：** 卡牌描述文本中的内嵌能量图标。

**规格：**

- 128x128
- 透明底 PNG

**设计要求：**

- 强符号化
- 不直接用人物头像
- 推荐方向：红色拳套 / 拳印徽记 / 红黑格斗能量符号
- 小尺寸下仍清晰

### C. 红色卡组共用卡图 `card_red.png`

**用途：** 当前大量红色卡牌默认共用插图。

**规格：**

- 512x512
- 透明底 PNG

**设计要求：**

- 体现 Tifa 风格近战角色的核心职业感
- 动作要有爆发力
- 红黑主色明确
- 画面主体集中，适合裁进卡牌小窗口
- 不要复杂背景，不要纯站桩

### D. 高频单卡插图

本轮优先替换以下 6 张：

#### 1. `card_attack_basic.png`
- 方向：基础近战直拳 / 格斗出拳

#### 2. `card_attack_big.png`
- 方向：更强爆发性的重拳 / 冲击拳

#### 3. `card_grant_energy.png`
- 方向：蓄力 / 聚气 / 战斗能量提升

#### 4. `card_weaken_enemies.png`
- 方向：压制、威慑、群体气势打断

#### 5. `card_block_basic.png`
- 方向：格挡、架势、防御动作

#### 6. `card_draft_random_attack.png`
- 方向：快速切换招式 / 组合拳选择感

**统一规格：**

- 512x512
- 透明底 PNG

**统一要求：**

- 与当前红色角色立绘同一人设
- 尽量保持同一服饰、发型、拳套设定
- 动作与卡牌语义一致
- 构图集中，避免主体过小

## 实施顺序

1. 先生成并替换 `character_red_icon.png`
2. 生成并替换 `character_red_text_energy.png`
3. 生成并替换 `card_red.png`
4. 再替换 6 张高频单卡插图
5. 逐步接入、验证游戏显示效果

## 验证标准

替换完成后，至少确认以下几点：

1. 新开局角色选择页中，红色角色头像风格与战斗立绘一致
2. 卡牌文本中的红色能量图标可辨识，且不会显得像缩小立绘
3. 红色卡牌共用图不再是旧机器人风格
4. 高频单卡在手牌中与角色立绘视觉统一
5. 所有资源尺寸、透明通道和路径均符合当前项目规范

## 风险与约束

### 风险

- 若直接用全身人物做 icon，缩小后会失去辨识度
- 若卡图背景过复杂，显示到卡牌中会发糊
- 若不同资源分别出图但缺乏统一锚点，仍会出现“像不同角色”的问题

### 约束

- 本轮不通过改代码解决风格问题
- 仅通过资源替换完成统一
- 如需更高一致性，后续再做红色角色整套资源扩展

## 结论

方案 B 是当前最合适的落地路径：在不扩大范围的前提下，优先统一最容易被玩家直接感知到的红色角色资源，快速消除当前 Tifa 立绘与旧机器人卡图之间的割裂感。
