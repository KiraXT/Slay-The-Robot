# 选关地图节奏与路线表现设计

## 目标

将选关地图从固定网格改成更接近《杀戮尖塔》的路线结构：底部显示起始点，每一层节点数量按种子随机变化，节点之间用虚线表现可行进路线，并保持现有图标图例与右侧布局不遮挡。

## 生成规则

- 起始点使用现有 `LocationData.LOCATION_TYPES.STARTING`，位于地图底部居中，并连接第一层所有可选节点。
- 普通楼层不再固定 5 个节点。每层使用世界生成 RNG 选择 3 到 5 个节点，并按该层节点数量居中排布。
- 特殊节奏保留现有大致层级：前期基础战斗，中段商店、小型 BOSS、宝箱、篝火，顶部大型 BOSS。
- 每个非起点、非 BOSS 节点必须至少有一条来自上一层的入边；每个上一层节点至少连接一个下一层节点；BOSS 连接上一层所有节点。

## 显示规则

- 地图 UI 不再跳过起始点。
- 线路绘制在节点下方，使用白蓝色虚线段，读取 `location_next_location_ids` 作为唯一数据来源。
- 节点图标保持此前的选关图例风格；起始点先复用基础战斗地图岛图标，后续如果有专用素材可单独替换。

## 验证

- 新增生成回归：验证起点存在、楼层节点数存在随机变化、路径不断路、BOSS 可达。
- 扩展 UI 回归：验证地图显示起点，存在路径绘制层，路线数量与数据连接数量一致，布局不遮挡右侧图例。
