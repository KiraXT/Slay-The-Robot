# 参考资源卡牌样式变体设计

## 目标

将当前卡牌样式包从“统一紫色切图覆盖”调整为基于参考资源的真实模块化变体。卡牌的阵营颜色、类型和标题可读性均应由卡牌数据驱动，同时避免多个完整底框叠加造成的拼接感。

本次只处理卡牌视觉层与预览工具，不改变卡牌数值、效果、交互逻辑或既有卡牌数据格式。

## 参考资源与约束

- 使用用户提供的卡牌组件参考图作为唯一的样式来源，拆分其中已有的边框、类型条、标题栏、能量徽章、插画框、描述底板与装饰元素。
- 禁止以 `ColorRect`、纯色 `StyleBoxFlat` 或运行时着色代替参考图中已经存在的彩色边框和类型条。
- 可以对已拆分的参考资源做无损裁切、透明背景处理、九宫格边距设置和比例适配；不得绘制新的色块来冒充素材。
- 当前已生成的统一紫色预览素材仅作为过渡输入，不得继续作为所有卡牌的最终覆盖层。

## 视觉结构

卡牌由以下独立层组成，从后到前排列：

1. 外框：按卡牌颜色选择真实的参考边框，承担卡牌的主要色彩识别。
2. 深色标题栏：独立于外框，使用参考图中的深色标题区域或由同一深色标题素材延展；卡名始终使用白色文字。
3. 插画框：使用参考资源的深色插画边框，不与外框重复绘制完整底板。
4. 类型条：按卡牌类型选择真实的彩色类型条，跨接插画区与描述区。
5. 描述底板与星级装饰：使用参考图白色正文底板及其角部装饰。
6. 能量徽章与发光：使用参考图拆分素材，保持现有可玩状态与高亮逻辑。

外框、插画框、描述底板各自只出现一次。布局将以当前 `Card.tscn` 的 144 x 184 逻辑尺寸为基准重新校正，保证标题栏、插画、类型条和描述区没有可见的双边框、断边或不对称留白。

## 数据映射

不修改 `CardData`。`Card.gd` 在现有 `card_color_id` 和 `card_type` 基础上从样式包选择对应的纹理槽位。

| 数据值 | 参考资源变体 |
| --- | --- |
| `color_red` | 红色外框 |
| `color_blue` | 蓝色外框 |
| `color_green` | 绿色外框 |
| `color_orange` | 金色外框 |
| `color_white` | 银白外框 |
| 攻击 | 红色“攻击”类型条 |
| 技能 | 绿色“技能”类型条 |
| 能力 | 蓝色“能力”类型条 |
| 状态 | 灰色“状态”类型条 |
| 诅咒 | 紫色“诅咒”类型条 |

没有映射的颜色使用银白外框，没有映射的类型使用灰色类型条。该回退只使用已拆分的参考素材。

## 样式包格式

保留 `external/data/card_styles/card_style_preview.json` 作为可替换入口，但扩展为三类纹理槽：

- `shared_slots`：标题栏、插画框、描述底板、能量徽章、发光等共用参考素材。
- `color_slots`：按 `card_color_id` 映射的真实外框素材。
- `type_slots`：按卡牌类型 ID 映射的真实类型条素材。

所有路径位于 `external/sprites/ui/card_styles/preview/`，方便未来替换为新的风格包而不修改卡牌逻辑。

## 运行时行为

`Card.update_card_display()` 先应用现有程序配色作为加载失败时的回退，再应用样式包的共用素材、颜色外框、类型条和标题文本规则。样式包或单个资源缺失时，卡牌保持可显示，并回退到当前程序化样式；不会阻断战斗、抽牌或卡牌交互。

## 预览与验收

新增预览组合图，至少展示五张不同颜色的卡牌，以及攻击、技能、能力、状态、诅咒五种类型条。验收条件：

- 黑色或深色标题栏上的卡名为白色，读取清晰。
- 五种卡牌颜色使用不同的参考边框素材，而非同一紫色素材或纯色染色。
- 五种类型条使用对应的参考彩条。
- 插画框、类型条和描述底板没有双重完整外框，也没有相邻边缘明显错位。
- 现有卡牌视觉回归测试和样式包回归测试通过，并新增颜色和类型映射断言。

## 非目标

- 不新增卡牌插画。
- 不改变卡牌尺寸、卡牌交互、鼠标悬停动画、能量计算或文本内容。
- 不为每个“颜色 x 类型”组合绘制整张卡牌；通过共享层与真实资源变体组合控制出图数量。
